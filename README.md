# Portfolio

This repository contains a personal portfolio website for Ummay Saima. The project is a single-page, responsive website built with plain HTML and CSS, with no backend or database. It is designed to present the owner’s introduction, experience, projects, skills, and contact details in a polished and modern layout.

## Project Overview

The website acts as a digital portfolio and online resume. It includes:

- A landing/hero section with a short introduction
- An About section with a personal description and timeline for experience/education
- A Projects section showing selected work samples
- A Skills section listing technical and design tools
- A Contact section with an email link and social links
- A downloadable CV file

This repository is intentionally simple: it is a static website that can be opened directly in a browser without installing dependencies or running a build step.

## What Is Included

The repository currently contains:

- `saima.html` — the main HTML file containing the full page structure, inline CSS, and content
- `cv.pdf` — a downloadable CV file
- Image assets such as `image.png`, `aa1.png`, `aa2.png`, `as1.png`, `as2.png`, `ob1.png`, and `ob2.png` used in the portfolio sections

## Technologies Used

The site is built with:

- HTML5 for structure
- CSS3 for styling and responsive layout
- Font Awesome for icons
- Google Fonts for typography

There is no JavaScript framework, no package manager setup, and no server-side application code in this repository.

## How to View the Project

Because this is a static website, you can view it directly.

### Option 1: Open the HTML file directly

Open `saima.html` in any web browser.

### Option 2: Serve it locally

If you prefer using a local web server, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/saima.html
```
